# SmartTransit

Kerala Public Transport Maps, Navigation, and Fare Portal.

## 🚀 Live Deployments

- **Vercel**: 👉 **[temporary-express-lagoon-jszfpk8.vercel.app](https://temporary-express-lagoon-jszfpk8.vercel.app)**
- **Surge**: 👉 **[kerala-smarttransit.surge.sh](http://kerala-smarttransit.surge.sh)**

---

## 🛠️ Features
- **Kerala Public Transport Data**: Metro stations, ferry routes, districts, and depots.
- **Maps & Navigation**: Integrated interactive Leaflet maps with OSRM routing.
- **Language Settings**: Multi-language support (Malayalam, Hindi, Tamil, Kannada, Bengali).
- **QR Ticket Scanner**: Built-in camera ticket scanner.
